⚙️ Chapter 2: Node.js Fundamentals & Async Patterns

Node.js is JavaScript running on the server. It allows us to build backends without learning a new language. Let's understand how Node.js works and the patterns used in backend development.

What is Node.js?

Node.js is a JavaScript runtime built on Chrome's V8 engine. It lets you run JavaScript outside the browser (on a server).

// This runs on the server, not in a browser!
console.log('Hello from Node.js');
const sum = 5 + 3;
console.log('Sum:', sum);

Synchronous vs Asynchronous

Synchronous: Code runs one line at a time, waits for each to finish.

// Synchronous - slow!
console.log('Start');
// Imagine this takes 10 seconds
doSomethingSlow();
console.log('End');  // Waits for doSomethingSlow() to finish

Asynchronous: Code doesn't wait. Other code runs while waiting for slow operations.

// Asynchronous - faster!
console.log('Start');
doSomethingSlowAsync().then(() => {
  console.log('Done!');
});
console.log('End');  // Runs immediately, doesn't wait

Promises

A Promise represents a value that will exist in the future (or might fail).

// Promise with .then() and .catch()
fetch('/api/auth/login', {
  method: 'POST',
  body: JSON.stringify({ email: 'user@example.com', password: '123' })
})
.then(response => response.json())  // Success path
.catch(error => console.log('Error:', error));  // Error path

Async/Await (Modern Way)

Async/await makes asynchronous code look like synchronous code (easier to read).

async function login(email, password) {
  try {
    const response = await fetch('/api/auth/login', {
      method: 'POST',
      body: JSON.stringify({ email, password })
    });
    const data = await response.json();
    console.log('Logged in!', data);
  } catch (error) {
    console.log('Login failed:', error);
  }
}

Callbacks

A callback is a function passed to another function. Used when operation completes.

// Reading a file with callback
fs.readFile('data.json', 'utf8', (error, data) => {
  if (error) {
    console.log('Error reading file:', error);
  } else {
    console.log('File contents:', data);
  }
});

Event Loop

Node.js uses an event loop to handle asynchronous operations:

1. Execute synchronous code
2. Check for async operations (timers, promises)
3. Execute callbacks when ready
4. Repeat until no more code

Common Node.js APIs

API Purpose Example
console.log() Print to console console.log('Debug info')
setTimeout() Run code after delay setTimeout(() => {}, 1000)
fs (File System) Read/write files fs.readFile('file.txt')
http Handle HTTP requests http.createServer()

Environment Variables

Store sensitive data (API keys, secrets) in environment variables, not in code:

// In .env file
GEMINI_API_KEY=sk-abc123...

// In your code
const apiKey = process.env.GEMINI_API_KEY;

Modules & Imports

Node.js uses modules to organize code:

// Exporting from authStore.js
export const users = new Map();

// Importing in login/route.js
import { users } from '@/lib/authStore';

Error Handling

Always handle errors gracefully:

async function processRequest(data) {
  try {
    // Code that might fail
    const result = await fetch('https://api.example.com/data');
    const json = await result.json();
    return json;
  } catch (error) {
    // Handle error
    console.error('Request failed:', error.message);
    return null;
  }
}

Key Takeaways

  • Node.js runs JavaScript on the server
  • Always use async/await for operations that take time
  • The event loop keeps Node.js responsive
  • Handle errors with try/catch
  • Use environment variables for secrets
  • Organize code into modules for reusability
