✅ Chapter 12: Status Codes & Error Responses

HTTP status codes tell the client what happened. Let's master them.

Status Code Categories

Code Category Meaning
2xx Success Request succeeded
3xx Redirect Must do something else
4xx Client Error Client made a mistake
5xx Server Error Server made a mistake

2xx Success Codes

Code Meaning When
200 OK Request succeeded, returning data
201 Created New resource created (POST)
202 Accepted Request accepted, processing async
204 No Content Success, no data to return (DELETE)

4xx Client Error Codes

Code Meaning When
400 Bad Request Invalid data, missing fields
401 Unauthorized Not logged in, invalid token
403 Forbidden Logged in but no permission
404 Not Found Resource doesn't exist
409 Conflict Data conflicts (email already exists)
429 Too Many Requests Rate limit exceeded

5xx Server Error Codes

Code Meaning When
500 Internal Server Error Unexpected server error
502 Bad Gateway Server unreachable
503 Service Unavailable Server down for maintenance

Using Status Codes Correctly

// GET existing resource
export async function GET(request, { params }) {
  const { id } = await params;
  const user = users.get(id);

  if (!user) {
    return Response.json(
      { error: 'User not found' },
      { status: 404 }  // ← Not Found
    );
  }

  return Response.json(user, { status: 200 });  // ← OK
}

// CREATE new resource
export async function POST(request) {
  const { email, password } = await request.json();

  // Validation error
  if (!email) {
    return Response.json(
      { error: 'Email required' },
      { status: 400 }  // ← Bad Request
    );
  }

  // Conflict (email already exists)
  const exists = Array.from(users.values()).find(u => u.email === email);
  if (exists) {
    return Response.json(
      { error: 'Email already registered' },
      { status: 409 }  // ← Conflict
    );
  }

  // Success - created
  const newUser = { id: uuid(), email, password };
  users.set(newUser.id, newUser);

  return Response.json(newUser, { status: 201 });  // ← Created
}

// UPDATE resource
export async function PUT(request, { params }) {
  const { id } = await params;
  const user = users.get(id);

  if (!user) {
    return Response.json(
      { error: 'User not found' },
      { status: 404 }  // ← Not Found
    );
  }

  const updates = await request.json();
  const updated = { ...user, ...updates };
  users.set(id, updated);

  return Response.json(updated, { status: 200 });  // ← OK
}

// DELETE resource
export async function DELETE(request, { params }) {
  const { id } = await params;

  if (!users.has(id)) {
    return Response.json(
      { error: 'User not found' },
      { status: 404 }  // ← Not Found
    );
  }

  users.delete(id);
  return Response.json(null, { status: 204 });  // ← No Content
}

Error Response Format

// Consistent error format
return Response.json(
  {
    success: false,
    error: 'Email already registered',
    errorCode: 'DUPLICATE_EMAIL',
    details: {
      field: 'email',
      value: 'john@example.com'
    }
  },
  { status: 409 }
);

Handling Errors in Try/Catch

export async function POST(request) {
  try {
    const { email, password } = await request.json();

    if (!email) {
      // Client's fault
      return Response.json(
        { error: 'Email required' },
        { status: 400 }  // 4xx
      );
    }

    // Authenticate with external service
    const result = await authenticateWithGoogle(email);

    if (!result) {
      // Server's fault (external service failed)
      return Response.json(
        { error: 'Authentication failed' },
        { status: 502 }  // 5xx
      );
    }

    return Response.json(result, { status: 200 });

  } catch (error) {
    // Unexpected error
    console.error('Unexpected error:', error);

    return Response.json(
      { error: 'Something went wrong' },
      { status: 500 }  // 5xx
    );
  }
}

Redirect Status Codes

import { redirect } from 'next/navigation';

// Temporary redirect (307)
export async function GET(request) {
  const url = new URL(request.url);
  if (url.pathname === '/api/old-endpoint') {
    return Response.redirect('/api/new-endpoint', 307);
  }
}

// Permanent redirect (301)
export async function GET(request) {
  return Response.redirect('https://newdomain.com', 301);
}

Status Code Decision Tree

Is request valid?
  ├─ No → 400 (Bad Request)
  │
  └─ Yes → Is user authenticated?
    ├─ No → 401 (Unauthorized)
    │
    └─ Yes → Does user have permission?
      ├─ No → 403 (Forbidden)
      │
      └─ Yes → Does resource exist?
        ├─ No → 404 (Not Found)
        │
        └─ Yes → Success!
          ├─ GET → 200 (OK)
          ├─ POST → 201 (Created)
          ├─ PUT → 200 (OK)
          └─ DELETE → 204 (No Content)

Key Concepts

  • 2xx: Success
  • 4xx: Client error (user's fault)
  • 5xx: Server error (our fault)
  • 400: Bad request (validation failed)
  • 401: Unauthorized (not logged in)
  • 403: Forbidden (no permission)
  • 404: Not found
  • 500: Server error
