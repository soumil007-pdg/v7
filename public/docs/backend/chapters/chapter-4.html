🔐 Chapter 4: Authentication System (Local & Token-Based)

Authentication is how we verify that a user is who they claim to be. ADVOCAT-Easy uses token-based authentication: when you log in, you get a token (unique string) that proves you're authenticated.

Authentication Flow

1. User enters email & password
   ↓
2. Frontend sends POST /api/auth/login with credentials
   ↓
3. Backend validates email & password
   ↓
4. If valid: Create a token (unique string)
   ↓
5. Send token back to frontend
   ↓
6. Frontend stores token (localStorage)
   ↓
7. For future requests: Send token in header
   ↓
8. Backend checks: "Is this token valid?"
   ↓
9. If valid: Allow the request. If not: Reject

Token-Based vs Session-Based

Token-Based Session-Based
Token stored on client Session ID stored on server
Stateless (server doesn't track) Stateful (server tracks sessions)
Good for mobile apps Good for web apps
ADVOCAT-Easy uses this Traditional approach

ADVOCAT-Easy's In-Memory Auth Store

ADVOCAT-Easy stores users and sessions in memory (not a database):

// lib/authStore.js
export const users = new Map();
export const sessions = new Map();

// users structure:
// userId → { id, email, password, createdAt }

// sessions structure:
// token → { userId, createdAt }

Signup Flow

// app/api/auth/signup/route.js
import { users } from '@/lib/authStore';
import crypto from 'crypto';
import bcrypt from 'bcryptjs';

export async function POST(request) {
  const { email, password } = await request.json();

  // Check if user already exists
  const existingUser = Array.from(users.values()).find(u => u.email === email);
  if (existingUser) {
    return Response.json(
      { error: 'Email already registered' },
      { status: 400 }
    );
  }

  // Hash the password
  const hashedPassword = await bcrypt.hash(password, 10);

  // Create new user
  const userId = crypto.randomUUID();
  users.set(userId, {
    id: userId,
    email: email,
    password: hashedPassword,
    createdAt: Date.now()
  });

  return Response.json({
    success: true,
    message: 'Account created'
  });
}

Login Flow

// app/api/auth/login/route.js
import { users, sessions } from '@/lib/authStore';
import crypto from 'crypto';
import bcrypt from 'bcryptjs';

export async function POST(request) {
  const { email, password } = await request.json();

  // Find user by email
  const user = Array.from(users.values()).find(u => u.email === email);

  if (!user) {
    return Response.json(
      { error: 'Invalid email or password' },
      { status: 401 }
    );
  }

  // Compare password with hash
  const passwordValid = await bcrypt.compare(password, user.password);

  if (!passwordValid) {
    return Response.json(
      { error: 'Invalid email or password' },
      { status: 401 }
    );
  }

  // Create session token
  const token = crypto.randomUUID();
  sessions.set(token, {
    userId: user.id,
    createdAt: Date.now()
  });

  return Response.json({
    success: true,
    token: token
  });
}

Validating Tokens

// app/api/auth/validate/route.js
import { sessions } from '@/lib/authStore';

export async function POST(request) {
  const { token } = await request.json();

  // Check if token exists
  const session = sessions.get(token);

  if (!session) {
    return Response.json(
      { error: 'Invalid token' },
      { status: 401 }
    );
  }

  // Check if token expired (24 hours)
  const age = Date.now() - session.createdAt;
  const maxAge = 24 * 60 * 60 * 1000; // 24 hours

  if (age > maxAge) {
    sessions.delete(token);
    return Response.json(
      { error: 'Token expired' },
      { status: 401 }
    );
  }

  return Response.json({
    valid: true,
    userId: session.userId
  });
}

Logout

// app/api/auth/logout/route.js
import { sessions } from '@/lib/authStore';

export async function POST(request) {
  const { token } = await request.json();

  // Delete the session
  sessions.delete(token);

  return Response.json({
    success: true,
    message: 'Logged out'
  });
}

Frontend: Storing the Token

// In browser, after successful login
const response = await fetch('/api/auth/login', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email, password })
});

const data = await response.json();

if (response.ok) {
  // Store token in localStorage
  localStorage.setItem('authToken', data.token);
  // Redirect to dashboard
  window.location.href = '/dashboard';
}

Frontend: Sending Token with Requests

// Get token from localStorage
const token = localStorage.getItem('authToken');

// Send with API request
const response = await fetch('/api/chat', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json',
    'Authorization': `Bearer ${token}`
  },
  body: JSON.stringify({ message: 'Hello' })
});

Key Concepts

  • Token: Unique string that proves you're logged in
  • Session: Server-side record linking token to user
  • Hash: One-way encryption of password (can't reverse)
  • Bearer Token: Token sent in Authorization header
  • Expiration: Tokens expire after a time (security)
