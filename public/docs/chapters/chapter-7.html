🎨 Chapter 7: Components & Reusability

Components are the building blocks. Let's learn to write DRY (Don't Repeat Yourself) components that you can use across pages.

What Makes a Good Component?

  • Single Responsibility: Does one thing well
  • Reusable: Can be used in many places
  • Configurable: Takes props to customize behavior
  • Predictable: Same props = same output

Example: Button Component

Instead of writing buttons inline everywhere, create a reusable Button:

// app/components/Button.jsx
'use client';

export default function Button({
  children,           // Button text
  onClick,            // Click handler
  variant = 'primary',  // 'primary' or 'secondary'
  disabled = false,
  className = ''
}) {
  const baseStyles = 'px-6 py-3 rounded-lg font-bold transition-all';

  const variants = {
    primary: 'bg-orange-500 text-white hover:bg-orange-600',
    secondary: 'bg-gray-200 text-gray-900 hover:bg-gray-300'
  };

  return (
    <button
      onClick={onClick}
      disabled={disabled}
      className={`${baseStyles} ${variants[variant]} ${className}`}
    >
      {children}
    </button>
  );
}

Now use it everywhere:

'use client';
import Button from '@/app/components/Button';

export default function LoginForm() {
  return (
    <form>
      <Button variant="primary">Sign In</Button>
      <Button variant="secondary">Forgot Password</Button>
    </form>
  );
}

Card Component with Slots

More advanced: a Card that wraps other components:

// app/components/Card.jsx
'use client';

export default function Card({
  title,
  subtitle,
  children,
  footer,
  className = ''
}) {
  return (
    <div className={`bg-white rounded-lg shadow-md p-6 ${className}`}>
      {title && <h2 className="text-2xl font-bold mb-2">{title}</h2>}
      {subtitle && <p className="text-gray-600 mb-4">{subtitle}</p>}

      <div className="mb-4">{children}</div>

      {footer && <div className="border-t pt-4 mt-4">{footer}</div>}
    </div>
  );
}

Use it to build layouts:

<Card
  title="Case Strategist"
  subtitle="Build your legal roadmap"
  footer={<Button>Start Now</Button>}
>
  <p>Share your situation and get expert guidance...</p>
</Card>

The Input Component

Standardize form inputs:

// app/components/Input.jsx
'use client';

export default function Input({
  label,
  type = 'text',
  placeholder,
  value,
  onChange,
  error,
  required
}) {
  return (
    <div className="mb-4">
      {label && (
        <label className="block font-semibold mb-2">
          {label}
          {required && <span className="text-red-500">*</span>}
        </label>
      )}

      <input
        type={type}
        placeholder={placeholder}
        value={value}
        onChange={onChange}
        className={`w-full p-3 border rounded-lg focus:outline-none focus:ring-2
          ${error ? 'border-red-500 ring-red-500' : 'border-gray-300 focus:ring-orange-500'}`}
      />

      {error && <p className="text-red-500 text-sm mt-1">{error}</p>}
    </div>
  );
}

Component Organization

app/components/
├── UI/
│   ├── Button.jsx
│   ├── Input.jsx
│   ├── Card.jsx
│   └── Modal.jsx
├── Layout/
│   ├── Navbar.jsx
│   ├── Footer.jsx
│   └── Sidebar.jsx
└── Features/
    ├── ChatWindow.jsx
    ├── AuthForm.jsx
    └── FAQAccordion.jsx
