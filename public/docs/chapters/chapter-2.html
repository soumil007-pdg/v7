HTML: The Skeleton

HTML is a markup language that structures content on a webpage. Think of it as the skeleton of a building—it defines what goes where.

Basic HTML Example

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>This is a paragraph.</p>
    <a href="https://example.com">Click me!</a>
  </body>
</html>

Key HTML Concepts

Tags

Tags are instructions wrapped in angle brackets. Examples: <h1>, <p>, <a>.

Rule: Most tags must be closed: <p>text</p>

Attributes

Attributes add extra information to tags. Example: <a href="url"> has an href attribute.

Semantic HTML

Use meaningful tags: <header>, <nav>, <main>, <footer>. This helps search engines and assistive tech understand your page.

Common HTML Tags You'll Use

<h1>...</h1>  <!-- Headings (h1 is largest, h6 is smallest) -->
<p>...</p>    <!-- Paragraph -->
<a href="url">...</a>  <!-- Link -->
<button>...</button>  <!-- Button -->
<input />  <!-- Text input field -->
<div>...</div>  <!-- Generic container -->
<img src="url" />  <!-- Image -->

CSS: The Styling

CSS makes things look pretty. It colors text, positions elements, creates animations, and responsive designs.

CSS Basics

/* This is a CSS rule */
h1 {
  color: blue;           /* Text color */
  font-size: 24px;       /* Font size */
  text-align: center;    /* Alignment */
}

Three Ways to Use CSS

1. Inline (Bad ❌)

<h1 style="color: blue;">Hello</h1>

Don't use this—it mixes HTML and CSS, making code messy.

2. In <style> tag (Okay ✅)

<style>
  h1 { color: blue; }
</style>
<h1>Hello</h1>

Good for small pages, but not scalable.

3. External CSS file (Best ✅✅)

<link rel="stylesheet" href="styles.css">
<h1>Hello</h1>
/* In styles.css */
h1 { color: blue; }

Professional approach—separates content from styling.

CSS Selectors: Targeting Elements

/* Select all h1 tags */
h1 { }

/* Select element with id="header" */
#header { }

/* Select all elements with class="title" */
.title { }

/* Select h1 tags INSIDE div */
div h1 { }

/* Select all h1 AND p tags */
h1, p { }

Useful CSS Properties

/* Color & text */
color: red;
background-color: yellow;
font-size: 16px;
font-weight: bold;
text-align: center;

/* Size & spacing */
width: 100%;
height: 200px;
margin: 10px;              /* Space OUTSIDE */
padding: 10px;             /* Space INSIDE */

/* Layout */
display: flex;             /* Makes children flex in a row */
display: grid;             /* Advanced layouts */
justify-content: center;   /* Align items horizontally */
align-items: center;       /* Align items vertically */

JavaScript: The Brain

JavaScript makes webpages interactive. It responds to clicks, fetches data, and updates the page without refreshing.

JavaScript Basics

// Variables (store data)
let name = "Alice";
const age = 25;  // const = can't change later

// Functions (reusable code)
function greet(person) {
  console.log("Hello, " + person);
}
greet("Alice");  // Prints: Hello, Alice

// Objects (store related data)
const user = {
  name: "Alice",
  age: 25,
  email: "alice@example.com"
};
console.log(user.name);  // Prints: Alice

The DOM: Interacting with HTML

The DOM (Document Object Model) is a JavaScript interface that lets you select and modify HTML elements.

// Find an element
const heading = document.getElementById("title");

// Change its text
heading.textContent = "New Title";

// Change its style
heading.style.color = "blue";

// Listen for clicks
const button = document.querySelector("button");
button.addEventListener("click", function() {
  console.log("Button clicked!");
});

Async/Await: Fetching Data

Modern web apps fetch data from servers. JavaScript's async/await makes this clean and readable.

// Fetch data from an API
async function getUser() {
  const response = await fetch("/api/users/1");
  const user = await response.json();
  console.log(user);  // {name: "Alice", age: 25}
}

getUser();

How They Work Together

In ADVOCAT-Easy, you'll see this pattern everywhere:

  1. HTML defines the page structure (buttons, inputs, text)
  2. CSS makes it look professional (colors, spacing, responsive)
  3. JavaScript makes it interactive (clicks, form submissions, API calls)

But in modern React apps, we write JavaScript that generates the HTML and CSS dynamically—which is why React is powerful!
