🔍 Chapter 10: SEO Optimization

SEO (Search Engine Optimization) makes your site appear in Google results. ADVOCAT-Easy implements best practices for rankings and visibility.

Core SEO Elements

1. Metadata (generateMetadata)

Titles and descriptions shown in Google search results:

// app/[locale]/dashboard/page.js
export async function generateMetadata({ params }) {
  const { locale } = await params;
  const t = await getTranslations({ locale, namespace: 'Dashboard' });

  return {
    title: t('metaTitle'),
    description: t('metaDescription'),
    alternates: {
      canonical: `https://advocat-easy.com/${locale}/dashboard`,
      languages: {
        en: `https://advocat-easy.com/en/dashboard`,
        hi: `https://advocat-easy.com/hi/dashboard`
      }
    }
  };
}

SEO Checklist

Unique title (50-60 chars) per page
Meta description (150-160 chars)
H1 tag with primary keyword
Fast page load (use Server Components)
Mobile responsive design
Sitemap.xml submitted to Google
