🔐 Chapter 8: Authentication System

Authentication (auth) verifies who the user is. ADVOCAT-Easy uses a simple token-based system. Let's see how it works.

How Token-Based Auth Works

SIGNUP:
  User enters email + password
    ↓
  Server hashes password (never store plain passwords!)
    ↓
  Server creates user record
    ↓
  Redirects to login

LOGIN:
  User enters email + password
    ↓
  Server checks password matches hash
    ↓
  Server creates unique token (UUID)
    ↓
  Server stores: token → {email, createdAt, expiresAt}
    ↓
  Returns token to client
    ↓
  Client stores in localStorage

ACCESSING PROTECTED PAGE:
  Page loads → useAuth() hook runs
    ↓
  Hook reads token from localStorage
    ↓
  Sends token to /api/auth/validate
    ↓
  Server checks: is token valid? Not expired?
    ↓
  If valid: page renders
  If invalid: redirects to /auth

LOGOUT:
  User clicks logout
    ↓
  Client calls /api/auth/logout with token
    ↓
  Server deletes the token from storage
    ↓
  Client removes token from localStorage

The useAuth Hook (Already Built)

ADVOCAT-Easy has a custom hook to check auth. Use it in any component:

// hooks/useAuth.js
import { useState, useEffect } from 'react';
import { useRouter } from 'next/navigation';

export function useAuth(requireAuth = true) {
  const [isLoggedIn, setIsLoggedIn] = useState(false);
  const router = useRouter();

  useEffect(() => {
    const token = localStorage.getItem('sessionToken');
    if (!token) {
      if (requireAuth) router.push('/auth');
      return;
    }

    // Validate token
    fetch('/api/auth/validate', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ token })
    })
      .then(res => res.json())
      .then(data => {
        if (data.isValid) {
          setIsLoggedIn(true);
        } else if (requireAuth) {
          router.push('/auth');
        }
      });
  }, []);

  return { isLoggedIn };
}

Protecting a Page with Auth

Make a page require login:

// app/[locale]/dashboard/DashboardClient.jsx
'use client';

import { useAuth } from '@/hooks/useAuth';

export default function DashboardClient() {
  const { isLoggedIn } = useAuth(true);  // true = must be logged in

  if (!isLoggedIn) {
    return <p>Loading...</p>;  // Show loading until auth check done
  }

  return <h1>Welcome to your dashboard!</h1>;
}

Authentication Best Practices

Never store passwords in plain text—always hash
Use HTTPS in production (tokens leak over HTTP)
Set token expiration (ADVOCAT-Easy: 7 days)
Use httpOnly cookies for extra security (not localStorage)
Validate tokens on every protected API call
Clear localStorage on logout
