📄 Chapter 6: Building Your First Page

Let's create a new page from scratch. You'll see how Server and Client Components work together, handle SEO, and add translations.

Step 1: Create the Page Files

Let's build a FAQ page at /en/faq.

# Create the folder
mkdir -p app/[locale]/faq

# Create two files
touch app/[locale]/faq/page.js
touch app/[locale]/faq/FAQClient.jsx

Step 2: Write the Server Page (page.js)

This handles SEO, translations, and auth checks:

// app/[locale]/faq/page.js
import { getTranslations, setRequestLocale } from 'next-intl/server';
import FAQClient from './FAQClient';

export async function generateMetadata({ params }) {
  const { locale } = await params;
  const t = await getTranslations({ locale, namespace: 'FAQ' });

  return {
    title: t('metaTitle'),           // "Frequently Asked Questions"
    description: t('metaDescription'),
    alternates: {
      canonical: `/${locale}/faq`,
      languages: {
        en: '/en/faq',
        hi: '/hi/faq',
        mr: '/mr/faq',
        te: '/te/faq'
      }
    }
  };
}

export default async function FAQPage({ params }) {
  const { locale } = await params;
  setRequestLocale(locale);  // For i18n

  return <FAQClient />;
}

Step 3: Write the Client Component (FAQClient.jsx)

This handles interactivity (opening/closing questions):

// app/[locale]/faq/FAQClient.jsx
'use client';

import { useState } from 'react';
import { useTranslations } from 'next-intl';

export default function FAQClient() {
  const t = useTranslations('FAQ');
  const [expandedId, setExpandedId] = useState(null);

  const faqs = [
    {
      id: 1,
      question: t('q1'),  // "Is this service free?"
      answer: t('a1')      // "Yes, ADVOCAT-Easy is free..."
    },
    {
      id: 2,
      question: t('q2'),
      answer: t('a2')
    }
  ];

  return (
    <main className="min-h-screen bg-gray-50 p-8">
      <div className="max-w-2xl mx-auto">
        <h1 className="text-4xl font-bold mb-8">{t('title')}</h1>

        {faqs.map((faq) => (
          <div key={faq.id} className="bg-white p-6 mb-4 rounded-lg shadow">
            <button
              onClick={() => setExpandedId(
                expandedId === faq.id ? null : faq.id
              )}
              className="w-full text-left font-semibold text-lg hover:text-orange-500"
            >
              {faq.question}
            </button>

            {expandedId === faq.id && (
              <p className="mt-4 text-gray-700">{faq.answer}</p>
            )}
          </div>
        ))}
      </div>
    </main>
  );
}

Step 4: Add Translations

Add FAQ translations to each language file:

// messages/en.json
{
  "FAQ": {
    "metaTitle": "Frequently Asked Questions - ADVOCAT-Easy",
    "metaDescription": "Get answers to common questions about ADVOCAT-Easy.",
    "title": "Frequently Asked Questions",
    "q1": "Is this service free?",
    "a1": "Yes, ADVOCAT-Easy is completely free to use...",
    "q2": "How accurate is the AI?",
    "a2": "Our AI uses the Indian Constitution and verified acts..."
  }
}

Step 5: Test the Page

Start the dev server and test:

npm run dev

Visit:

  • http://localhost:3000/en/faq → English
  • http://localhost:3000/hi/faq → हिन्दी
  • Click the questions to expand/collapse answers

Key Takeaways

Server page (page.js) = SEO, metadata, translations
Client component (*Client.jsx) = state, hooks, interactivity
Always add translations to messages/*.json
Use useTranslations() in client components
generateMetadata() for SEO titles and descriptions
