🎨 Chapter 12: Styling with Tailwind CSS

Tailwind CSS is a "utility-first" CSS framework. Instead of writing CSS files, you write classes directly in your HTML. It's fast, consistent, and scales well.

What is Tailwind?

Tailwind gives you pre-made CSS classes for everything: colors, spacing, typography, layouts.

Old Way:

/* styles.css */
.button {
  background-color: #FF5B33;
  color: white;
  padding: 12px 24px;
  border-radius: 8px;
}

Tailwind Way:

<button class="bg-orange-500 text-white px-6 py-3 rounded-lg">
  Click me
</button>

Tailwind Basics

Spacing

<div class="p-4">...</div>  <!-- padding: 1rem -->
<div class="px-8 py-4">...</div>  <!-- padding left & right -->

Colors

<div class="bg-blue-500">...</div>  <!-- Background blue -->
<p class="text-red-600">Error</p>  <!-- Text red -->

Layout (Flexbox & Grid)

<!-- Flexbox (row) -->
<div class="flex justify-between items-center">
  <div>Left</div>
  <div>Right</div>
</div>

<!-- Grid -->
<div class="grid grid-cols-3 gap-4">
  <div>Col 1</div>
  <div>Col 2</div>
</div>

Responsive Design

<!-- Mobile: 1 column, Desktop: 3 columns -->
<div class="grid grid-cols-1 lg:grid-cols-3">
  ...
</div>
