🏗️ Chapter 5: ADVOCAT-Easy Architecture

Now that you understand React and Next.js, let's see how ADVOCAT-Easy is organized. This architecture is production-ready and scales from one feature to many.

Folder Structure Deep Dive

📁 app/[locale]/ — Localized Pages

app/[locale]/
├── page.js          → Homepage
├── layout.js        → Global header, navbar
├── error.js         → Error boundary
└── [feature]/
    ├── page.js      → Server wrapper (SEO)
    └── [Feature]Client.jsx → Client component

Key Concepts

  • Server Pages: Handle SEO, metadata, translations
  • Client Components: Handle state, hooks, interactivity
  • API Routes: Backend endpoints at app/api/*
  • Translations: messages/*.json for multi-language support
  • Custom Hooks: Reusable logic in hooks/
